# Method

First reconstruct the rotation-group and complex Fourier shift identities
symbolically for arbitrary real phase projections; this is the decisive
universal derivation. Then run 7,680 deterministic rotary trials and 192 finite Fourier trials. Cross-check
the independent NumPy implementation against author functions extracted
verbatim by AST. An additive absolute positional encoding is the negative
control and must break shared-translation invariance.
